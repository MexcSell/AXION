## Important
- **I1. "Another person approves" hides the two-administrator rule (Organization proposals; also Agent version proposals).** The code (`server/src/organization/proposals.ts`: requireAdmin on propose and decide, `SELF_APPROVAL` 403) requires a second administrator. With one administrator (the stated owner setup) a proposal can never be applied. The page says "Someone proposes ... Another person approves", which reads as any second person, or the owner approving alone. Say: "Only administrators can propose and decide, and the person who proposed cannot approve their own: you need two administrators." Same for version proposals ("a different person reviews", LOG: promotions need two admins): say "a second administrator". Also the proposals "Honest limits" is empty; this belongs there.
- **I2. "Instead of editing the org chart directly" is too absolute.** Creating an agent (`POST /agents`) still writes a new org revision directly (single admin, audited), and Q5 says direct agent edits stay single-admin. Proposals are the governed route for changing reporting lines, not the only way the chart changes. Reword to "reporting lines can be changed through a proposal ... (adding an agent still adds its line directly)".
